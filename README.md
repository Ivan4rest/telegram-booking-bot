# Telegram-бот записи на услуги

Демо-проект: бот для салона, барбершопа или клиники. Клиент выбирает услугу, день и свободное время, администратор получает уведомление, а бот сам напоминает о визите.

*Telegram booking bot (aiogram 3, SQLite): service → day → free time slot → phone, admin notifications, reminders before the visit, cancellation.*

## Что умеет

- Запись по шагам: услуга → день → свободное время → телефон.
- Не даёт записаться на занятое время: уникальность слота проверяет база данных.
- Уведомляет администратора о новой записи и об отмене.
- Напоминает клиенту за 2 часа до визита.
- «Мои записи» с отменой для клиента, команда `/admin` со списком предстоящих записей для администратора.

Название, услуги, цены и часы работы меняются в `config.py`.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой числовой Telegram ID (например, у @userinfobot) — на него будут приходить уведомления.
3. Скопируйте `.env.example` в `.env` и впишите `BOT_TOKEN` и `ADMIN_ID`.
4. Установите зависимости и запустите:

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt   # Linux/macOS: .venv/bin/pip
.venv/Scripts/python bot.py
```

## Тесты

```bash
.venv/Scripts/pip install pytest
.venv/Scripts/python -m pytest
```

## Устройство

| Файл | Назначение |
|---|---|
| `bot.py` | Сценарии диалога и фоновая задача напоминаний |
| `db.py` | Хранение записей в SQLite, поиск свободных слотов |
| `config.py` | Настройки: услуги, часы работы, глубина записи |

## Ограничения демо

- Один мастер и слоты по часу; для нескольких мастеров и услуг разной длительности нужна доработка схемы.
- Время берётся с сервера, без учёта часового пояса клиента.
